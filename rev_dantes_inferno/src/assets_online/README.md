# Online Art Sources

All derived scene sprites are 64x64 indexed BMP files. Run
`tools/build_scene_sprites.py` with Pillow to rebuild the first four assets.

- Source: https://opengameart.org/content/lpc-bears-deer-lions-and-more

- Source: https://opengameart.org/content/pixel-wolf
